# Heart Disease Prediction using Random Forest

## Overview
This project uses a Random Forest classification model to predict the likelihood of heart disease based on patient health data.

The project was created for learning and portfolio purposes to practice:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning using Random Forest
- Model evaluation

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory Data Analysis
3. Feature selection
4. Train-test split
5. Random Forest model training
6. Model evaluation and prediction

## Results
The model achieved moderate performance and helped demonstrate the complete machine learning workflow from data preparation to evaluation.
